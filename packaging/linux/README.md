# Будущая упаковка Linux

В этой папке появятся только рабочие рецепты `deb`, `rpm` и AppImage после переноса общего ядра Sora на поддерживаемый Linux-рантайм.

До появления такого ядра здесь намеренно нет `control`, spec-файла, AppDir и фиктивного исполняемого файла: они создавали бы пакеты, которые устанавливаются, но не подключают VPN.

Общие требования к будущим пакетам:

- конфигурация пользователя хранится в каталоге XDG, а не рядом с бинарником;
- системная служба устанавливается отдельно от интерфейса и получает только необходимые права;
- удаление пакета восстанавливает системный прокси и маршруты;
- зависимости и лицензии входят в пакет явно;
- один и тот же тест импорта подписок и сетевого подключения выполняется для всех трёх форматов.
