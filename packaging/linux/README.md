# Упаковка Linux

Рабочий тестовый `deb` собирается Compose Desktop из `clients/sora-kmp/desktopApp`. Он не публикуется как релиз до ручной проверки подключения, восстановления прокси и удаления пакета.

Локальная сборка в Linux:

```sh
cd clients/sora-kmp
./gradlew :shared:jvmTest :desktopApp:packageDeb
```

Пакет появляется в `desktopApp/build/compose/binaries/main/deb`. libXray v26.7.28 скачивается во время сборки и принимается только при совпадении закреплённой SHA-256.

Общие требования к будущим пакетам:

- конфигурация пользователя хранится в каталоге XDG, а не рядом с бинарником;
- TUN доступен только процессу с правами root; обычный запуск предоставляет системный прокси без повышения прав;
- удаление пакета восстанавливает системный прокси и маршруты;
- зависимости и лицензии входят в пакет явно;
- общий тест импорта, раздельности подписок и конфигурации подключения выполняется до упаковки.

RPM и AppImage будут добавлены только после проверки `deb`; пустых рецептов в репозитории нет.
