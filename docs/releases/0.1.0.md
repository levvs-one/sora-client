# Sora 0.1.0

Первый публичный выпуск `sora-client` — монохромного клиентского приложения для Windows 7 SP1 x86.

## Что входит

- единый установщик: Sora, Xray-core, sing-box, tun2proxy, Wintun, GeoIP и GeoSite;
- автоматическая проверка .NET Framework 4.8 и KB3033929 с установкой только при необходимости;
- подписки, группы серверов, поиск, маршрутизация, системный прокси и режим TUN через tun2proxy;
- интерфейс в геометрии Happ с монохромной палитрой и Phosphor Icons Bold;
- диагностика без экспорта подписок, серверных адресов и локального имени пользователя;
- сохранение и точное восстановление исходных настроек WinINET/PAC, включая восстановление при удалении после аварийного завершения.

## Установка

1. Скачайте `Sora-0.1.0-Win7-x86-Setup.exe`.
2. Сверьте SHA-256 по файлу `Sora-0.1.0-SHA256SUMS.txt`.
3. Запустите установщик. Для системных компонентов Windows может запросить повышение прав.

## Ограничения

- Целевая система — Windows 7 SP1 x86; на этой машине проверены сборка и полный цикл установки, запуска и удаления, но отдельной физической Windows 7 x86 для финальной проверки не было.
- Установщик пока не подписан сертификатом Authenticode, поэтому Windows или антивирус могут показать предупреждение.
- Проект не связан с OpenAI, Happ или Flyfrog. Название Sora используется только как название этого независимого клиента.

Полные исходники соответствующего выпуска находятся в теге `v0.1.0` и отдельном source-архиве релиза.
