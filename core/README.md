# core

`libsora`: сетевое ядро Sora на Go. Один и тот же код работает внутри службы ядра на Windows и Linux и внутри Android-службы туннеля.

## Что здесь будет

| Пакет | Назначение |
| --- | --- |
| `cmd/sora-core` | Точка входа службы ядра для Windows и Linux |
| `mobile` | Привязки gomobile для Android |
| `control` | Сервер `sora.core.v1`, проверка доступа, шина событий |
| `engine` | Супервизор сессии, сборка конфигурации sing-box, мост к Xray-core |
| `platform` | Адаптеры TUN, системного прокси, DNS и kill switch для каждой ОС |
| `stateguard` | Журнал изменений состояния ОС и восстановление после сбоя |
| `parser` | Распознавание форматов, разбор ссылок и подписок |
| `probe` | Проверки серверов реальным трафиком и обнаружение блокировок |
| `bypass` | Умный обход: каталог стратегий, ранжирование, поиск и восстановление |
| `errors` | Каталог ошибок `SoraErrorCode` и маскирование секретов |

## Правила

- Сетевые движки работают в одном процессе. Цепочки через локальные порты запрещены.
- Конфигурация sing-box собирается из типизированных структур, а не из шаблонов JSON.
- Каждое изменение состояния ОС записывается в журнал до применения.
- Проверки: `gofmt`, `go vet`, `go test -race`, `golangci-lint` с настройками из `.golangci.yml`.
