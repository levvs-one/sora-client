# История изменений

Все заметные изменения Sora перечисляются в этом файле. Версии следуют Semantic Versioning.

## [0.2.0] - 2026-08-29

### Добавлено

- Единое окно добавления с автоматическим распознаванием HTTPS-подписок, VMess, VLESS, Trojan, Shadowsocks, SOCKS, Base64, SIP008 и Xray JSON.
- Собственный редактор серверов Sora с проверкой обязательных полей, портов, транспорта и параметров безопасности.
- Собственные меню серверов, текста, журналов, резервных копий и значка в области уведомлений.
- Монохромные обозначения стран и дополнительные иконки Phosphor Icons Bold.

### Изменено

- Список серверов получил двухстрочную структуру, понятное активное состояние и читаемую плотность без старой горизонтальной прокрутки.
- Системные окна выбора файлов заменены автоматическим сохранением резервных копий, экспортов и диагностики в каталоги Sora.
- Кнопка подключения использует спокойную пульсацию без вращающегося декоративного кольца.
- Модальные окна поддерживают клавиатурную навигацию, Enter, Escape и доступные имена кнопок.

### Исправлено

- Контекстное меню применяется к серверу под курсором, а не к ранее выбранной строке.
- Небезопасная HTTP-подписка больше не сохраняется как успешно добавленная: интерфейс сразу требует HTTPS.
- Повторный экспорт не перезаписывает файл, созданный в ту же секунду.
- Недоступный повышенный процесс ядра больше не прерывает штатный запуск Sora и не засоряет журнал ошибкой доступа.

[0.2.0]: https://github.com/levvs-one/sora-client/releases/tag/v0.2.0

## [0.1.0] - 2026-08-29

### Добавлено

- Первый публичный выпуск Sora для Windows 7 SP1 x86.
- Единый установщик с условной установкой .NET Framework 4.8 и KB3033929.
- Xray, sing-box, tun2proxy и Wintun в совместимых 32-разрядных сборках.
- Подписки, маршрутизация, входящие подключения, статистика и фильтруемые журналы.
- Безопасный диагностический архив без конфигураций подключения и учётных данных.

### Изменено

- Интерфейс v2rayN заменён монохромным интерфейсом Sora.
- Системный прокси и TUN адаптированы для legacy-среды Windows 7 x86.
- Самообновление приложения отключено, чтобы официальные сборки устанавливались только из релизов `sora-client`.

### Исправлено

- Исключён запуск системного прокси без выбранного активного сервера.
- Устранён сбой журнала при записи до создания оконного дескриптора.
- Сборочный каталог очищается от пользовательских конфигураций, журналов и отладочных файлов.

[0.1.0]: https://github.com/levvs-one/sora-client/releases/tag/v0.1.0
