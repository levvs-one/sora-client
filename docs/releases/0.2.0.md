# Sora 0.2.0

Выпуск полностью заменяет оставшиеся пользовательские элементы старого WinForms-интерфейса в основных сценариях Sora и ускоряет добавление подписок и серверов.

## Что изменилось

- одно поле принимает HTTPS-подписки, VMess, VLESS, Trojan, Shadowsocks, SOCKS, Base64, SIP008 и Xray JSON и само определяет формат;
- неподдерживаемые Clash/Mihomo, NaiveProxy и Hysteria отклоняются до сохранения, потому что для них в комплекте нет рабочего совместимого x86-ядра;
- системные окна добавления, редактирования, подтверждения, резервного копирования, экспорта и диагностики заменены интерфейсом Sora;
- серверы отображаются двумя строками с протоколом, транспортом, TLS, задержкой и монохромным кодом страны;
- верхние оконные кнопки и действия используют Phosphor Icons Bold;
- в списке серверов `Ctrl+V` открывает импорт, `Ctrl+C` копирует ссылку, `Enter` выбирает активный сервер, а `Delete` удаляет после подтверждения; `Escape` закрывает диалоги;
- резервные копии сохраняются в `Документы\Sora\Backups`, экспортированные конфигурации — в `Документы\Sora\Exports`, а диагностические ZIP — в `Загрузки` с резервным сохранением в `Документы`;
- исправлены выбор строки правым кликом, клавиатурная навигация, повторный экспорт и запуск рядом с повышенным процессом ядра.

## Установка

1. Скачайте `Sora-0.2.0-Win7-x86-Setup.exe`.
2. Сверьте SHA-256 по файлу `Sora-0.2.0-SHA256SUMS.txt`.
3. Запустите установщик. Зависимости устанавливаются только при необходимости.

## Важные ограничения

- Целевая система — Windows 7 SP1 x86. На машине сборки проверяются x86-сборка, установка, запуск и удаление; физическая Windows 7 x86 для этого выпуска недоступна.
- Установщик не подписан сертификатом Authenticode, поэтому Windows или антивирус могут показать предупреждение.
- HTTP-подписки намеренно не загружаются: используйте HTTPS.
- Проект независимый и не связан с OpenAI, Happ или Flyfrog.

Исходники выпуска находятся в теге `v0.2.0` и в source-архиве релиза.
