# Для провайдеров

Sora открывает те же подписки, что Happ, v2rayN, Hiddify и другие клиенты. Отдельный формат делать не нужно.

## Что Sora понимает в теле подписки

- список ссылок, по одной в строке, или он же в base64;
- ссылки `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://` (`hy2://`), `tuic://`, `wireguard://` (`wg://`), `socks://`, `http://`, `https://`;
- конфигурации WireGuard и AmneziaWG в формате `.conf` (с секциями `[Interface]` и `[Peer]`);
- SIP008 (JSON Shadowsocks);
- JSON-подписки Xray, в том числе от Remnawave. Каждый объект конфигурации становится отдельным сервером и работает целиком: с балансировщиками, observatory и маршрутами провайдера. Sora добавляет к нему свой вход, DNS, блокировку рекламы и выбранные пользователем маршруты.

Из JSON-конфигурации Sora убирает то, что даёт провайдеру доступ к машине пользователя или его файлам: блок `reverse`, все `inbounds` и ключи с путями к файлам (`masterKeyLog`, `certificateFile`, `keyFile`). Сертификаты, переданные прямо в конфиге, работают.

## Заголовки ответа

Sora читает те же заголовки, что и другие клиенты. Если заголовков нет, те же строки можно положить в начало тела подписки, по одной в строке, в первых десяти строках.

| Заголовок | Что показывает Sora |
| --- | --- |
| `profile-title` | название подписки, до 128 символов. Можно в base64 с префиксом `base64:` |
| `subscription-userinfo` | `upload=...; download=...; total=...; expire=...`: расход трафика и срок действия |
| `profile-update-interval` | как часто обновлять, в часах |
| `profile-web-page-url` | ссылка «Сайт провайдера» |
| `support-url` | ссылка «Поддержка», может быть `https://` или `tg://` |
| `announce` | объявление, до 2048 символов, можно `base64:`. Ссылки и `@имена` в нём кликабельны |
| `Content-Disposition` | название, если нет `profile-title` |

Подписку Sora запрашивает с заголовком `User-Agent: sora-core/1 (+https://github.com/levvs-one/sora-client)`. Если панель выбирает формат по User-Agent, добавьте для Sora тот же ответ, что для Happ или v2rayN. Пользователь может поставить свой User-Agent в настройках подписки.

Ограничения: только `https://`, не больше пяти редиректов, тело до 16 МБ, загрузка до 30 секунд. Редирект с адреса в интернете на адрес в локальной сети не выполняется.

## Группы через названия серверов

Серверы одной подписки с одинаковым названием Sora показывает одной строкой. Трафик идёт через самый быстрый из них, сервер, который не ответил на проверку, не выбирается.

Если в конце названия указана роль, сначала используется основной сервер, запасной включается, когда основной не отвечает.

| Название в подписке | Как работает |
| --- | --- |
| `Нидерланды (основной)` | строка «Нидерланды», трафик идёт сюда |
| `Нидерланды (запасной)` | включается, когда основной не отвечает |
| `Германия`, `Германия` | строка «Германия», самый быстрый из двух |
| `Белые списки main`, `Белые списки backup` | строка «Белые списки», порядок по ролям |

Слова для основного: `основной`, `главный`, `main`, `primary`. Для запасного: `запасной`, `резерв`, `резервный`, `backup`, `reserve`, `fallback`. Регистр не важен. Роль можно взять в скобки или отделить пробелом, дефисом, двоеточием или запятой. Сервер без роли в группе, где роли указаны, считается запасным.

Порядок по ролям выполняет ядро mihomo, и для таких групп Sora выбирает его сама. Если пользователь вручную закрепил sing-box или Xray, используются только основные серверы, самый быстрый из них. Для JSON-подписок Xray переключение делает само приложение: если текущий профиль не поднялся, запускается следующий.

В других клиентах эти серверы видны по отдельности, с теми же названиями, так что одна ссылка подходит всем.

## Кнопка «Добавить в Sora»

Ссылки, которые открывают добавление подписки в Sora:

```
sora://add/https://panel.example.com/sub/TOKEN
sora://add?url=https%3A%2F%2Fpanel.example.com%2Fsub%2FTOKEN&name=Example
```

Sora понимает и ссылки других клиентов: `happ://add/...`, `v2rayn://install-config?url=...`, `clash://install-config?url=...&name=...`, `hiddify://import/...#name`, `sing-box://import-remote-profile?url=...#name`. Поэтому кнопка «Добавить в Happ» на сайте провайдера тоже откроет Sora, если Happ на компьютере не установлен.

Зашифрованные ссылки `happ://crypt...` Sora не читает. Если на сайте есть только они, добавьте рядом обычную ссылку на подписку.

Подписка добавляется только после того, как пользователь нажмёт «Добавить» в окне Sora.
