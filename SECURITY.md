# Безопасность

Исправления выпускаются для последней версии Sora.

Об уязвимости сообщайте закрыто: вкладка Security, кнопка Report a vulnerability. Публичный issue для этого не подходит.

В отчёте укажите версию Sora, систему и шаги воспроизведения. Реальные ссылки подписок, ключи, UUID и адреса серверов замените тестовыми значениями.

Sora не отвечает за серверы провайдеров. Проблемы конкретного сервера решайте с его владельцем.
