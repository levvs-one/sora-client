# Платформы Sora

## Windows

Все Windows-сборки собираются из одной кодовой базы. Это сохраняет одинаковое поведение импорта, подписок, прокси, TUN, проверки задержки и журналов.

| Файл | Целевая система | Архитектура | Состояние |
| --- | --- | --- | --- |
| `sora_win7.exe` | Windows 7 SP1 | x86 | основной профиль совместимости |
| `sora_win8.exe` | Windows 8.1 | x86 | профиль сборки и установщика |
| `sora_win10.exe` | Windows 10 | x86, работает на x64 через WoW64 | профиль сборки и установщика |
| `sora_win11.exe` | Windows 11 | x86, работает на x64 через WoW64 | профиль сборки и установщика |

Windows 8.0 не входит в матрицу: .NET Framework 4.8 официально поддерживает Windows 8.1, но не Windows 8.0. Короткое имя `sora_win8.exe` относится именно к Windows 8.1.

Каждый профиль проходит одинаковый набор регрессионных проверок в CI. Это подтверждает сборку и поведение кода, но не заменяет запуск на реальной машине соответствующей версии Windows.

Локальная сборка всех четырёх профилей:

```powershell
.\build\Build-WindowsProfiles.ps1
```

Профиль установщика задаётся определениями Inno Setup. Например, для Windows 8.1 используются `WindowsTarget=win8`, `WindowsDisplayName=Windows 8.1` и `MinimumWindowsVersion=6.3`. Для Windows 10 и 11 задаются соответственно `10.0` и `10.0.22000`.

## Linux

Linux пока не выпускается. Подготовлены направления упаковки:

- `deb` для Debian и Ubuntu;
- `rpm` для Fedora, openSUSE и совместимых систем;
- AppImage как переносимая сборка без системной установки.

Пакеты появятся после выделения общего ядра подписок и подключений из Windows-клиента. До этого в репозитории не публикуются пустые пакеты или бинарники, которые только показывают интерфейс.

## Позже
