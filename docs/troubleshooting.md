# Если что-то не работает

Сначала откройте «Настройки», «Журнал». Там записи службы и всех ядер. Чтобы увидеть больше, поставьте «Что записывать: Всё» и повторите действие. Журнал можно сохранить в файл кнопкой «Сохранить в файл». Ссылки подписок, ключи и адреса серверов в журнале скрыты, его можно прикладывать к issue.

## «Служба Sora не отвечает»

Приложение не может подключиться к службе.

Linux:

```sh
systemctl status sora-core
journalctl -u sora-core -e
sudo systemctl restart sora-core
```

Если службы нет совсем, не установлен пакет `sora-core`.

Windows: откройте «Службы» (`services.msc`) и проверьте, что служба Sora core (`SoraCore`) запущена. Причину остановки служба пишет в журнал Windows: «Просмотр событий», «Журналы Windows», «Приложение», источник `SoraCore`. Из PowerShell:

```powershell
sc.exe query SoraCore
Get-WinEvent -FilterHashtable @{ LogName = 'Application'; ProviderName = 'SoraCore' } -MaxEvents 5
```

Помогает переустановка поверх: установщик обновит службу.

## «Нет доступа к службе Sora»

Linux пускает к службе того, кто сидит за компьютером: это проверяет polkit. Не пустит, если вы зашли по SSH или сессия неактивна. На машине без polkit добавьте себя в группу `sora` и перезайдите:

```sh
sudo usermod -aG sora $USER
```

Windows пускает пользователя активной сессии и администраторов. Второй пользователь, вошедший на тот же компьютер через смену пользователя, управлять VPN первого не может.

## «Обновите Sora: приложение и служба разных версий»

Приложение и служба поставлены от разных выпусков. На Linux обновите оба пакета, `sora` и `sora-core`. На Windows запустите установщик последней версии.

## Подписка не добавляется

- «Нужна ссылка, начинающаяся с https://»: Sora принимает только `https://`. Ссылку по `http://` попросите у провайдера в защищённом виде.
- «Не удалось загрузить подписку»: сайт провайдера недоступен. Если он заблокирован, подключитесь через другую подписку или режим «Без сервера» и добавьте снова.
- «В подписке нет серверов»: провайдер отдал пустой ответ или формат для другого клиента. Попробуйте в настройках подписки User-Agent того клиента, для которого провайдер делал подписку, например `Happ/2.0` или `v2rayN/7.0`.
- «Это не ссылка на подписку»: вставлено что-то другое. Для ссылки на один сервер (`vless://...`) провайдер обычно даёт и ссылку на подписку.

## Подключение не устанавливается

- «Сервер не ответил вовремя» и «Нет связи с сервером»: сервер недоступен из вашей сети. Выберите другой или «Самый быстрый». Если блокирует провайдер интернета, включите «Фрагментация TLS».
- «Не найдено ядро для этого сервера»: в настройках закреплено ядро, которое этот сервер не умеет. Поставьте «Ядро: Авто».
- «Нет прав на создание VPN-подключения»: служба не может создать адаптер. На Linux проверьте, что запущена именно служба `sora-core`, а не ядро вручную. На Windows переустановите Sora.
- «Не удалось включить блокировку интернета без VPN»: kill switch не включился. На Linux нужен пакет `nftables`.

## После Sora не работает интернет

Если Sora была закрыта аварийно, могли остаться её настройки.

Kill switch на Linux:

```sh
sudo nft delete table inet sora
```

На Windows правила kill switch пропадают сами, когда служба останавливается.

Системный прокси: откройте Sora, при запуске она вернёт прежний прокси сама. Или выключите его вручную: Windows, «Параметры», «Сеть и Интернет», «Прокси»; GNOME, «Настройки», «Сеть», «Прокси сети».

## Нет значка в трее

На Linux значку нужна панель с поддержкой StatusNotifierItem. В GNOME для этого нужно расширение AppIndicator. В Waybar добавьте модуль `tray`. Если панель запускается позже Sora, значок появится, когда она запустится.

## Сайт открывается не через VPN

Проверьте «Маршруты»: с вариантом «Россия напрямую» российские сайты идут напрямую. Проверьте «Свои правила». Посмотреть, куда пошло соединение, можно в «Настройки», «Соединения»: там видно правило и сервер для каждого.

## Проверка службы из терминала

```sh
sora-core -version
sudo -u sora sora-core -check -data-dir /var/lib/sora -engines-dir /usr/lib/sora/engines
```

`-check` проверяет, что ядра на месте и запускаются, и пишет, чего не хватает.
