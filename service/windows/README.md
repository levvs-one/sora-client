# service/windows

Установка и жизненный цикл службы ядра `SoraCore` на Windows 10 и 11. Код службы находится в `core/cmd/sora-core`, здесь лежит все, что связывает ее с системой.

## Что здесь будет

- Регистрация службы, учетная запись с минимальными правами и восстановление после сбоя.
- Права на именованный канал `\\.\pipe\sora-core`: доступ только у интерактивных пользователей.
- Установка драйвера Wintun.
- Удаление фильтров WFP kill switch при удалении приложения.
