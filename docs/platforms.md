# Платформы Sora

## Windows

Все Windows-сборки собираются из одной кодовой базы. Это сохраняет одинаковое поведение импорта, подписок, прокси, TUN, проверки задержки и журналов.

| Файл | Целевая система | Архитектура | Состояние |
| --- | --- | --- | --- |
| `sora_win7.exe` | Windows 7 SP1 | x86 | основной профиль совместимости |
| `sora_win8.exe` | Windows 8.1 | x86 | профиль сборки и установщика |
| `sora_win10.exe` | Windows 10 | x86, работает на x64 через WoW64 | профиль сборки и установщика |
| `sora_win11.exe` | Windows 11 | x86, работает на x64 через WoW64 | профиль сборки и установщика |

Windows 8.0 не входит в матрицу: .NET Framework 4.8 официально поддерживает Windows 8.1, но не Windows 8.0. Короткое имя `sora_win8.exe` относится именно к Windows 8.1.

Каждый профиль проходит одинаковый набор регрессионных проверок в CI. Это подтверждает сборку и поведение кода, но не заменяет запуск на реальной машине соответствующей версии Windows.

Локальная сборка всех четырёх профилей:

```powershell
.\build\Build-WindowsProfiles.ps1
```

Профиль установщика задаётся определениями Inno Setup. Например, для Windows 8.1 используются `WindowsTarget=win8`, `WindowsDisplayName=Windows 8.1` и `MinimumWindowsVersion=6.3`. Для Windows 10 и 11 задаются соответственно `10.0` и `10.0.22000`.

## Linux

Linux-клиент находится в проверочной ветке и пока не выпускается. Рабочая реализация использует общий интерфейс Compose и libXray:

- HTTPS-импорт и отдельное управление каждой подпиской;
- локальные SOCKS/HTTP-порты и автоматическая настройка прокси в GNOME и KDE;
- восстановление прежних настроек прокси после отключения и после нештатного завершения;
- TUN через Xray только при наличии прав root; без прав этот режим недоступен в интерфейсе;
- хранение настроек по XDG и сборка тестового `deb` в CI.

Тестовый `deb` остаётся артефактом CI до ручной проверки. RPM и AppImage не создаются, пока не проверен сетевой жизненный цикл `deb` на реальной системе.

## Android

Android-клиент также не выпущен. В нём реализованы общий менеджер подписок и собственный интерфейс Sora, foreground `VpnService`, запрос системного разрешения, защита сокетов ядра от зацикливания, TUN и восстановление последней конфигурации службы Android. Прокси-режим поднимает локальные SOCKS/HTTP-порты; для всего устройства используется TUN.

Debug APK собирается только как артефакт CI для ручной проверки. Публикации в GitHub Releases и магазины нет.

## Позже

macOS и iOS отложены. Windows XP потребует отдельного старого рантайма, TLS-стека и совместимого сетевого ядра; текущая сборка на .NET Framework 4.8 там не запускается.
