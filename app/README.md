# app

Приложение Sora на Flutter. Сейчас собирается под Linux; Windows, Android и Android TV —
следующие. Приложение работает от имени пользователя и управляет ядром только через контракт
`sora.core.v1`. Подписки и их серверы хранит и обновляет ядро, в зашифрованном виде; приложение
держит у себя только выбор человека: сервер, маршруты, переключатели.

## Устройство

| Путь | Что там |
| --- | --- |
| `lib/main.dart` | Запуск, тема, локализация, клавиши |
| `lib/src/sora.dart` | Состояние приложения и всё, что оно просит у ядра; сборка плана подключения |
| `lib/src/core/link.dart` | Связь с ядром по unix-сокету: Handshake, токен, переподключение |
| `lib/src/settings.dart` | Настройки на этом компьютере, с версией формата для миграций |
| `lib/src/design` | Палитра, шрифт, движение, свечение, логотип |
| `lib/src/ui` | Экраны: главный, серверы, настройки, журнал, о приложении |
| `lib/l10n` | Строки на русском и английском |
| `android/tunnel` | Android-служба туннеля |

## Дизайн

- Шрифт Inter 4.1 (OFL) лежит в `assets/fonts` и не скачивается во время работы.
- Цвет один — спектр свечения Apple Intelligence. Он появляется только как свет вокруг кнопки
  и края окна, пока идёт подключение и пока оно держится. Всё остальное — нейтральные тона.
- Ни линий между строками, ни надзаголовков: группы разделяет воздух.
- Анимации выключаются в настройках и сами следуют системной настройке «уменьшить движение».

## Разработка

```sh
flutter pub get
flutter test
flutter run -d linux
```

Ядро системной установки слушает `/run/sora/core.sock`. Ядро, запущенное вручную, слушает свой
сокет, и приложение находит его по переменной окружения:

```sh
sora-core -socket "$XDG_RUNTIME_DIR/sora-core.sock" -data-dir ~/.local/share/sora-dev/core
SORA_CORE_SOCKET="$XDG_RUNTIME_DIR/sora-core.sock" flutter run -d linux
```

Версию выпуска сборка получает через `--dart-define=SORA_VERSION=…`; без неё экран
«О приложении» честно пишет `dev`.
