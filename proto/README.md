# proto

Контракт `sora.core.v1` между приложением Sora и сетевым ядром. Из этих файлов генерируется код для Go (`core`) и Dart (`app`).

## Правила

- Контракт версионируется. Несовместимые изменения выпускаются только в новом пакете, например `sora.core.v2`.
- Каждое сообщение имеет ограничение размера, описанное в комментарии к RPC.
- Ошибки передаются только как `SoraError` с кодом из каталога ошибок.
- Проверки: `buf lint` и `buf breaking` с настройками из `buf.yaml`.
