# Изменения

## 1.0.5 (8 октября 2026)

- Kill switch включается вместе с подключением: правила firewall встают до запуска ядра, и в первые секунды ничего не уходит мимо туннеля. Раньше они включались отдельным запросом сразу после подключения.
- Уведомление, когда группа с ролями или выбранный сервер с переключением при сбое перешли на запасной сервер, и когда основной снова отвечает и трафик вернулся на него. Работает с ядром mihomo.
- Ядро возвращает группы и серверы по их id из плана, а не по именам, которые видит mihomo, и берёт задержку каждого сервера группы из его собственной проверки.
- Kill switch, переключённый во время подключения, применяется, когда подключение завершится. Раньше выключение в этот момент обрывало подключение.
- Приложение, переподключившись к службе, продолжает события сессии с того места, где остановилось, и не показывает уведомления повторно.

## 1.0.4 (8 октября 2026)

Первый выпуск нового клиента для Windows и Linux. Версии 1.0.1–1.0.3 были собраны, но не выпущены.

- Приложение для Windows 10 1809+ и 11 (установщик) и Linux (.deb, .rpm, Arch).
- Служба `sora-core` с ядрами sing-box 1.14.2, Xray 26.3.27 и mihomo 1.19.32. Ядро выбирается под каждый сервер автоматически.
- Подписки: обновление по расписанию, трафик и срок, объявления провайдера, свой User-Agent. JSON-подписки Xray (Remnawave).
- Группировка серверов по названиям, порядок по ролям «основной» и «запасной».
- Режимы TUN и системный прокси.
- Kill switch: nftables на Linux, WFP на Windows.
- Переподключение при смене сети и после сна.
- Свои правила для сайтов, IP-адресов и программ, маршруты для России, Ирана и Китая, блокировка рекламы.
- Обход DPI без сервера через zapret (Linux).
- Трей, автозапуск, уведомления.
- Ссылки `sora://`, `happ://add` и ссылки других клиентов открывают добавление подписки.
- Установка одной командой: `install.sh` для Linux, `install.ps1` для Windows.

Старый клиент для Windows 7 и его история изменений находятся в ветке [`legacy`](https://github.com/levvs-one/sora-client/tree/legacy).
