# Как предложить изменения

1. Откройте issue или напишите в существующий, если изменение большое.
2. Одна задача в одном pull request.
3. Перед отправкой прогоните проверки той части, которую меняли:
   - ядро: `cd core && go test ./... && golangci-lint run`
   - приложение: `cd app && flutter analyze && flutter test`
   - контракт: `cd proto && buf lint && buf breaking --against '.git#branch=main,subdir=proto'`
4. Исправление ошибки сопровождайте тестом, который без исправления падает.
5. Не прикладывайте реальные ссылки подписок, ключи, UUID и адреса серверов ни в код, ни в логи, ни в скриншоты.

Pull request сливается, когда проходят все проверки CI, включая сборку и живой тест на Windows.

Старый клиент для Windows 7 находится в ветке [`legacy`](https://github.com/levvs-one/sora-client/tree/legacy). В неё принимаются только исправления безопасности и серьёзных ошибок, pull request открывайте в эту ветку.
