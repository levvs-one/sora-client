# Windows: проверка центров Sora

Проверено 5 сентября 2026 на Windows 11 x64. Центры собраны для .NET Framework 4.8, x86. Это не подтверждение работы на настоящих Windows 7, 8 или 10.

## Автоматические проверки

| Проверка | Результат |
| --- | --- |
| Release-сборка Sora Logs и Sora Update | Пройдена, без ошибок и предупреждений |
| Разделение подписок, Markdown, локализация, локальные порты | `Sora.SubscriptionRegression.ps1`: пройдена |
| Многострочные логи, Unicode, лимиты, блокировка, дописывание и ротация файлов | `Sora.LogsRegression.ps1`: пройдена |
| Разрешённые адреса обновлений, подписи, повреждение файла, UTF-8 | `Sora.UpdateRegression.ps1`: пройдена |
| Подписанный список версий через HTTP и загрузка файла | `Sora.UpdateScenarios.ps1`: пройдена |
| Повреждённый файл, HTTP 503, повторная попытка | Пройдена |
| Отмена загрузки, позднее завершение после отмены | Пройдена, установка заблокирована |
| Повторные события ошибки для одного скачивания | Одно итоговое сообщение |
| Изменение подписанного списка версий | Отклонено |

HTTP-сценарии используют локальный сервер и временные ключи. Файл не является установщиком и никогда не запускается. Рабочие подписки, системный прокси и маршруты не изменяются. Проверки добавлены в Windows-задачи CI; результат нового удалённого запуска нужно смотреть отдельно.

## Проверка окон

Sora запускается из тестового комплекта. Sora Update открывается из настроек и определяет версию клиента. Без встроенного ключа проверка, скачивание и установка отключены с объяснением. Sora Logs открывается отдельно; чтение и пауза проверены.

Полный проход по клавиатурной навигации, масштабу интерфейса и всем фильтрам не завершён. В старом журнале предыдущей тестовой сборки осталась запись в другой кодировке; исходный файл не изменялся. Новая запись UTF-8 проверяется отдельным тестом.

## До выпуска

- Настроить постоянный ключ и публикацию подписанных списков версий.
- Проверить обновление настоящим установщиком с сохранением настроек, отказом UAC, нехваткой места и прерыванием установки.
- Проверить Windows 7/8/10 на соответствующих системах.
- Пройти реальные подключения, DNS, смену Proxy/TUN, сон, перезагрузку и восстановление системного прокси.
- Закончить проверку окон на разных DPI и языках.

Успешная сборка и тесты компонентов не означают готовность всего клиента к production. Релиз по результатам этого прогона не публиковался.
