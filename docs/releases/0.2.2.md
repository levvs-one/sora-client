# Sora 0.2.2

Исправляющий выпуск для импорта подписок и проверки задержки.

## Что исправлено

- Sora распознаёт ответ подписки в виде JSON-массива полных конфигураций Xray и создаёт отдельную запись для каждого совместимого профиля.
- Смешанные ответы обрабатываются безопасно: совместимые VLESS, VMess, Trojan, Shadowsocks, SOCKS, HTTP и WireGuard импортируются, неподдерживаемые протоколы пропускаются.
- Крупный JSON больше не обрезается встроенным ограничением поля WinForms: окно принимает до 4 МБ.
- Обновление подписки стало транзакционным. Если загрузка или разбор не удались, прежние серверы и их файлы остаются на месте.
- Временный сетевой таймаут получает одну повторную попытку с небольшой задержкой.
- Кнопка «Тест пинга» измеряет TCP-задержку до реального адреса и порта, в том числе у полных конфигураций Xray, без внешнего HTTP-сервиса.

## Проверка выпуска

- Проект собран как `net48/win7-x86`.
- Реальный ответ подписки размером 106 КБ распознан как 10 совместимых профилей из 11; неподдерживаемый Hysteria корректно пропущен.
- Чистый экземпляр Sora импортировал 10 профилей через собственное окно, показал числовой TCP-пинг и сохранил все 10 после перезапуска.
- Встроенный Xray 25.9.11 принял все 10 сохранённых конфигураций в режиме проверки.

Во время финальной проверки сам сервер тестовой подписки перестал принимать TCP-соединения, поэтому сетевой сбой отдельно подтверждён как безопасный: пустой результат не заменяет ранее сохранённые данные.

## Установка

1. Скачайте `Sora-0.2.2-Win7-x86-Setup.exe`.
2. Сверьте SHA-256 по файлу `Sora-0.2.2-SHA256SUMS.txt`.
3. Запустите установщик. .NET Framework 4.8 и KB3033929 устанавливаются только при необходимости.

Установщик не подписан Authenticode. Исходный код выпуска находится в теге `v0.2.2` и в автоматически сформированном source-архиве GitHub.
