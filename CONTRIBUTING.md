# Участие в разработке

## Перед изменением

1. Проверьте существующие issues.
2. Для крупной функции сначала создайте issue с пользовательской проблемой и предполагаемым поведением.
3. Не добавляйте реальные ссылки подписок, UUID, адреса серверов и учётные данные в код, тесты или журналы.

## Требования к изменениям

- Целевая платформа приложения — `net48/win7-x86`.
- Новая зависимость должна поддерживать .NET Framework 4.8 и Windows x86.
- Интерфейс остаётся монохромным: чёрный, белый и нейтральный серый без цветовых акцентов.
- Новые экраны не должны использовать стандартные светлые элементы WinForms.
- Нельзя коммитить `bin`, `obj`, пользовательские конфигурации, журналы и собранные установщики.
- Изменение поведения должно быть описано в `CHANGELOG.md`.

## Проверка

```powershell
dotnet restore .\v2rayN\v2rayN\v2rayN.csproj --runtime win7-x86
dotnet build .\v2rayN\v2rayN\v2rayN.csproj --configuration Release --runtime win7-x86 --no-restore
```

Перед pull request проверьте чистый запуск, импорт конфигурации, выбор сервера, системный прокси, TUN, журналы и удаление приложения.

## Лицензия

Отправляя изменение, вы соглашаетесь распространять его по GNU GPL-3.0 вместе с остальным проектом. Сохраняйте уведомления об авторстве и лицензии сторонних компонентов.
